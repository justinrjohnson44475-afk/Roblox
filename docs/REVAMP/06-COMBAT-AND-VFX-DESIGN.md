# Combat, networking and VFX

The signature test replaces request-time damage with a server timeline. Requests use version 2, session ID, monotonic bounded sequence and normalized horizontal aim. Reject malformed/replayed envelopes before resource changes; a token bucket bounds requests and permits defensive release at exhaustion. Requests contain no damage, target list, marker authorization or reward amount.

CombatService owns resources/acceptance/cooldowns, Timeline owns phase/cancel transitions, HitboxService samples measured blade trajectories over elapsed active intervals, and EncounterService checks membership/damage/contribution. Per-attack hit sets reject repeat hits. BuildAdapter retains Strider’s consumed post-dash bonus and Arcanist’s cheaper/stronger burst and longer reach. Wider burst/Overdrive extend the timed source blade volume rather than restoring request-time radius damage; matching magical reach presentation and balance require Studio review. Hitbox validation constrains range/facing/movement and raycasts obstruction. Skipped ticks cover the remaining active interval. Burst/Overdrive currently use their authored blade trajectory too; their gauntlet/area identity needs playtest-led refinement.

Guard/parry apply only to frontal ordinary attacks. Initial parry window .16s; guard costs18 stamina per block, passes30% damage; insufficient stamina breaks guard for .7s. Marked core charge requires evasion or Corebreak. Heavy/Coreburst/Overdrive contribute break damage; 6% of frozen scaled max boss health exposes for3.5s, ×1.75 damage. These provisional Warden values require tests for solo/four-player fairness. First-contact break damage receives exposed multiplier by current design.

Events version1 carry server attack ID (player strikes), encounter ID, result, position/material, synchronized presentation timestamp and deterministic seed. Predictions are presentation only; accepted sequence stops the local predicted track, timeout removes rejected prediction. Explicit rejection events stop predicted tracks; attack-window/cooldown prediction and latency correctness remain incomplete and require engine evidence.

Presentation pool caps256 desktop/96 touch. Debris is anchored, noncolliding, nonquerying, nontouching and expires1.3s; reusable slots avoid accumulation. Distance reduces particles; camera motion is restrained and can be disabled. Trails use BladeBase/BladeTip and TrailOn/TrailOff markers. Text distinguishes core warnings from blockable strikes. Initial destruction never edits terrain/navigation. Temporary surface cracks, displaced architectural panels, dust textures, shockwaves and material-specific visual responses are pending. The current primitive debris/telegraph is a test aid, not final cinematic VFX.

Gate B: solo and four clients, no immediate damage before active windows, one hit per attack, obstruction/no cross-party hits, front/back defense, Corebreak interrupt/exposure, death/reset cleanup, 0/100/200ms prediction acceptance/rejection captures. Cloud domain tests cover selected invariants only.
