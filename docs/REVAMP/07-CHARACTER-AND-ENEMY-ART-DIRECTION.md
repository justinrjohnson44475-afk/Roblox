# Character and enemy art direction

Original stylized cinematic fantasy: midnight cloth, ivory forged armor, muted bronze edges and a narrow mint relic accent. A broad asymmetric relic blade pairs with a left gauntlet. The hero should read as athletic and capable, not a floating collection of accessories. The Warden is articulated stone, horned crown, overgrown shoulders and an obvious exposed chest core; environmental fragments echo its material language.

`assets/ascension/source/Ascension.blend` contains the first original draft meshes and named R15 skeleton. Three FBX exports and 30 source clips exist. The Blender source preview shows those models, **not Roblox rendering**. The FBX importer, skin weights/joint compatibility, mesh segmentation, normalized dimensions and final silhouette quality remain unverified. Warden shell gaps and hero surface detail still need art refinement; these are production inputs, not finished hero bodies.

The test place uses a transparent neutral R15 collision proxy with a blade proxy, clearly labeled by the HUD. Import the actual FBX through Studio, validate ownership and dimensions, then replace it. Do not mistake source preview registration for a published animation pipeline.

After gate B: four coherent evolution silhouettes (base cloth/guard, awakened chest/gauntlet, ascendant shoulder/back contour, stormforged integrated blade/crown contour), using existing form IDs0–3. Avoid oversized cosmetics changing hitboxes. After first hero validation: second body silhouette, three hairstyles and six skin palettes without stats. Schema supports selections; actual alternatives/ownership/preview UI are not implemented. Collision proxies, LODs and atlas consolidation remain production tasks.
