# World and map overhaul

Current new content is a compact156×156 signature test arena with arrival steps, circular ruins, sanctuary pad and stable boundaries. It is cloned into pooled encounter slots512 studs apart. This is neither the flagship region nor proof of streaming/collision correctness. Baseline world remains in the default build.

Gate C follows a validated Warden slice. Build Verdant Reach at roughly480×480 with arrival overlook, first threat within15s, grove-ruin loop, vertical traversal, optional discovery, return shortcut and Warden sanctuary. Place meaningful interactions ≤15s walking apart along the primary route. At17 studs/s a straight255-stud segment is already15s; measure actual winding route lengths and elevation, not only Euclidean distance. Put the first opportunity within100–180 traversable studs and capture actual player timings.

Use a reusable original kit: stone wall/arch/column modules, stepped platforms, root bridges, varied foliage clusters and bronze relic insets. Reuse materials, limit unique texture memory, provide separate collision proxies and stream boundaries at occluded thresholds. Foliage should frame routes rather than fill combat sightlines. Place introductions in playable space; a dismissible subtitle/camera cue must not take movement control.

[WORLD-DESIGN-BIBLE.md](WORLD-DESIGN-BIBLE.md) records regional identity and route design. Ember Scar/Astral Crown production rebuilds remain blocked by gate B; do not multiply unfinished art across the existing progression map.
