# Riftwake roadmap

## Completed cloud work
- Source/community research correction, explicit footage-access limitation and five-concept replacement decision.
- Character-centered RPG design, three authored regions and baked edit-mode world.
- Server combat/encounter code, charge-break windows, boss phases and participant rewards.
- XP/abilities, deterministic upgrades, build paths, region/first-clear gates and visible rig evolution.
- Safe profile migration/persistence adapter, HUD/input/forge/settings and optional Christian reading.
- Domain/mock/DOM tests, binary/XML builds, previsualization tooling and CI artifact workflow.

## Next priority gates
1. Execute actual Studio solo/two-client/device sessions; fix engine errors and combat feel before broadening content.
2. Observe real players using the study in document 08. Test skill vs spam, first ability/evolution, next-region motivation and fatigue.
3. Validate real persistence, shutdown, services and authority in a private test universe.
4. Resolve content classification, contextual theological review, rights and production art/audio.
5. Expand encounter variation and equipment interactions only if the basic action loop earns independent return behavior.
6. Configure ethical cosmetic offers and analytics after private tests; owner-authorized closed-beta publishing.
7. Measured D1/D7/D30 cohorts, economics and sustainable live operations inform any launch/expansion.

The old Harborlight plan is superseded. “Masterpiece” is an ambition to earn through actual quality and player evidence, not a status label for this build.
