# Asset production manifest

All present world objects are original anchored primitive placeholders created in World.luau. No external meshes, copyrighted characters, marketplace models or audio downloads are used. UI uses Roblox built-in fonts. Optional local feedback uses a built-in Roblox sound path, which still needs engine/device verification.

Replace before beta: hero lighthouse silhouette, modular timber pier, greenhouse, original supply crate, accessible lantern color/material variants, warm ambient loop, contribution chime, three repair sounds, icon and thumbnails. Record creator, source, commercial rights, attribution, moderation asset ID and approval date for every replacement. Do not commit unlicensed assets. Budget and performance targets require measured low-end-device tests. Icons must show actual cooperative restoration; never fake rewards or imply the game is officially endorsed.
